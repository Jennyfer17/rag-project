PRAGAS E DOENÇAS DA COUVE E REPOLHO
1. INTRODUÇÃO
As pragas e doenças das culturas constituem um dos principais pro­
blemas que os agricultores enfrentam no processo de produção. 
Elas danificam as plantas, diminuindo o rendimento ou o valor dos 
produtos colhidos, tornando-os impróprios para o consumo e para 
a comercialização. 
O principal objectivo destq brochura de “PRAGAS E DOENÇAS DA 
COUVE E REPOLHO” é de informar aos produtores sobre as pragas e 
doenças mais importantes que podem ocorrer nas culturas da cou­
ve e repolho na região sul de Moçambique, e sobre os métodos de 
controlo a usar, que sejam eficazes, económicos e ambientalmente 
saudáveis. 
Esta brochura faz parte de um conjunto de materiais desenvolvidos 
no âmbito do projecto de Apoio ao Programa Nacional de Extensão 
Agrária (PSP), financiado pelo IFAD com a finalidade de aumentar a 
capacidade técnica e de gestão dos produtores e fortalecer a capaci­
dade dos serviços de extensão na prestação de serviços agrários aos 
produtores.

O que é a traça da couve?
3
3 É uma lagarta de cor verde e de tamanho pequeno (12mm)
3
3 Os adultos são pequenas borboletas de cor castanha
3
3 As fêmeas depositam ovos verdes isolados ou em grupos nas 
folhas
3
3 As pequenas lagartas nascem dos ovos e alimentam-se das 
folhas, podendo destruir toda a planta
Como controlar a traça da couve?
3
3 Usar inimigos naturais como a vespinha Cotesia plutellae (ver 
página 26)
3
3 Proteger os inimigos naturais usando pesticidas selectivos 
que não são nocivos para os inimigos naturais e que apenas 
matem a traça da couve (ver página 30)
3
3 Fazer a rotação de culturas e consociação usando o pimento, 
piri-piri, alho, cebola, coentro, feijão verde, feijão nhemba
3
3 Aplicar insecticidas botânicos como por exemplo sementes e 
folhas da margosa (Pó de sementes: 20-50g/litro de água; Pó 
das folhas - 100g/litro de água) e misturar a calda com sabão 
líquido a uma dose de 10ml/20litros de água para garantir a 
aderência
3
3 Queimar ou enterrar bem os restolhos depois da colheita
3
3 Aplicar insecticidas quando a infestação for superior a uma 
larva por planta (ver página 30)

O que são afídeos?
3
3 São insectos pequenos (1,5 a 2.5mm), de cor verde-
acinzentado que vivem em colónias
3
3 A infestação das plantas começa com os adultos com asas 
que vêm de fora do campo e
3
3 Ninfas e adultos vivem em grupos nos dois lados da folha, 
sugam a seiva da plantas
3
3 As folhas ficam distorcidas e as plantas gravemente atacadas 
murcham
Como controlar os afídeos?
3
3 Observar regularmente as folhas e arrancar as folhas mais 
velhas e infestadas
3
3 Eliminar os restos da cultura após a colheita
3
3 Proteger os inimigos naturais: joaninhas e sirfídeos (ver página 
27)
3
3 Fazer a rotação de culturas com culturas que não são da família 
das brássicas como por exemplo feijões ou abóbora
3
3 Fazer a consociação com plantas repelentes como por exemplo 
cebola e alho
3
3 Usar extractos botânicos como: mistura de alho e margosa, 
pimento vermelho + sabão líquido (50 gramas da mistura em 
2 litros de água, ferver por 15 minutos e deixar arrefecer e 
pulverizar)
3
3 Aplicar solução de sabão líquido (10-15 colheres de sopa para 
20litros de água)
3
3 Aplicar insecticidas quando a infestação for elevada (ver página 
30)

O que é a lagarta gregária da couve?
3
3 É uma lagarta de cor verde escura, com linhas claras e cabeça 
de cor castanho claro, tamanho médio (20-40 mm)
3
3 O adulto é uma borboleta de cor castanha
3
3 As borboletas põem cerca de 241 ovos em grupos nas folhas, 
as pequenas lagartas nascem dos ovos e alimentam-se das 
folhas
3
3 As folhas são completamente roídas e cobertas por teias e 
excrementos das lagartas que vivem agrupadas em colónias
Como controlar a lagarta gregária da couve?
3
3 Fazer a monitoria do campo uma vez por semana, 40 dias 
após o transplante
3
3 Fazer a destruição dos restos da cultura após a colheita 
3
3 Fazer a rotação de culturas e consociação usando o pimento, 
alho, cebola, coentro, feijão verde, feijão nhemba
3
3 Aplicar insecticidas botânicos como por exemplo a margosa
3
3 Aplicar insecticidas quando a infestação for grave (ver página 
30)

O que é a broca da couve?
3
3 É uma larva com a cor creme, com linhas laterais de cor 
castanho-vermelho e cabeça preta, tamanho pequeno 
(15mm)
3
3 Os adultos são borboletas de cor castanho-acinzentados
3
3 As borboletas colocam os ovos nas folhas mais jovens
3
3 As larvas nascem dos ovos, penetram e se alimentam 
dentro das nervuras, pecíolos, caules e destroem o ponto de 
crescimento da planta
Como controlar a broca da couve?
3
3 Fazer a monitoria regular do campo
3
3 Usar plântulas sãs para o transplante
3
3 Remover e destruir as plantas atacadas
3
3 Destruir todos os restos da cultura logo após a colheita
3
3 Aplicar insecticidas botânicos como por exemplo a margosa
3
3 Aplicar insecticidas apenas quando a infestação for grande 
(ver página 30)

PRAGAS E DOENÇAS DA COUVE E REPOLHO
O que é a rosca?
3
3 É uma lagarta de cor cinzento-escura e com aspecto gorduroso 
e de tamanho médio (30-45mm)
3
3 Os adultos são borboletas de cor castanha
3
3 As larvas nascem dos ovos que são postos pelas borboletas 
nas folhas junto ao solo 
3
3 As larvas vivem no solo durante o dia e à noite saem para a 
superfície para se alimentar, cortando as plantinhas na base
Como controlar a rosca?
3
3 Inundar o solo para que as lagartas abandonem os seus 
esconderijos durante o dia, tornando-se expostas aos 
predadores e a condições ambientais adversas
3
3 Aplicar um insecticida granulado ao redor da base do caule 
da planta (ver página 30) 
3
3 Espalhar farelo misturado com insecticida em volta dos pés 
das plantas

O que é a podridão negra?
3
3 É uma doença causada por uma bactéria 
3
3 Os sintomas típicos são: manchas amareladas à acastanhadas 
em forma de “V” na margem das folhas
3
3 A infecção das plantas pode ser através de:

Sementes contaminadas pela bactéria;

Restolhos contaminados pela bactéria no campo; e 

Solos contaminados pela bactéria.
3
3 A doença é favorecida por condições de humidade e 
temperaturas entre 25°C a 30°C
Como controlar a podridão negra?
3
3 Usar variedades resistentes 
3
3 Usar sementes certificadas e livres da doença
3
3 Eliminar os restos das culturas infectadas no campo
3
3 Fazer rotação de culturas num intervalo de pelo menos 2 
anos (com batata e cebola)
3
3 Aplicar pesticidas à base de cobre para reduzir a dispersão 
(ver página 31)

O que é a podridão mole?
3
3 A podridão mole é uma doença causada por uma bactéria 
3
3 Os sintomas caraterísticos são: murcha da planta, amolecimento 
dos tecidos e apodrecimento rápido, acompanhado de libertação 
de um líquido com mau cheiro.
3
3 A infecção das plantas pode ser através de:

Restolhos de brássicas ou outras hortaliças contaminados pela 
bactéria no campo; e 

Solos contaminados pela bactéria.
3
3 A doença geralmente ocorre na fase final da cultura e é favorecida 
por condições de humidade e temperaturas entre 25°C a 30°C
Como controlar a podridão mole?
3
3 Evitar ferimentos das plantas durante as operações culturais
3
3 Fazer rotação de culturas com gramíneas nas áreas afectadas
3
3 Evitar deficiências de Cálcio, Boro e Molibdénio
3
3 Usar variedades resistentes

O que é a hérnia das crucíferas? 
3
3 É uma doença causada por um fungo do solo, cujos sintomas 
característicos são a murcha da planta nas horas mais 
quentes do dia e a malformação de raízes (grossas e curtas), 
chamadas galhas. Quando a doença é grave ocorre a morte 
das plantas.
3
3 As plantas podem ser infectadas pelos esporos do fungo 
presentes no solo.
3
3 A hérnia das crucíferas é favorecida por solos arenosos 
e húmidos. Solos ácidos, isto é, com pH menor que 7.0, 
e temperaturas entre 20-25°C são também condições 
favoráveis à ocorrência da doença 
Como controlar a hérnia das crucíferas?
3
3 Usar plântulas sãs
3
3 Fazer a rotação de culturas com famílias diferentes das 
brássicas (Cenoura, beterraba e gramíneas não são 
hospedeiras da doença)
3
3 Remover as plantas infestadas da família das brássicas
3
3 Fazer a calagem dos solos ou aplicar matéria orgânica rica em 
cálcio
